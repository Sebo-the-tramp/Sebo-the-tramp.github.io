Open dataset ↗

High-resolution sensor data (RGB cameras and LiDAR) collected by Waymo self-driving cars in diverse conditions, released for non-commercial research use. · Source

Origin
Real
Depth
LiDAR range images and camera projections (Perception)
Sensors
RGB cameras, LiDAR

Dimensions

  • 2,030 segments of 20s each · Perception Dataset · Source
  • 390,000 frames at 10 Hz · Perception Dataset · Source
  • 1.2M object frames from 31K unique object instances · Perception object assets (vehicles and pedestrians) · Source
  • 103,354 segments · Motion Dataset · Source
  • 5,000 segments · End-to-End Driving Dataset · Source

Data types

  • RGB camera images (5 cameras) · Source
  • dense 3D LiDAR point clouds · Source
  • projected lidar returns on camera (depth) · Source
  • 3D semantic segmentation ground truth labels · Source
  • auto-labeled 2D panoptic segmentation · Source
  • 3D maps and object trajectories (Motion) · Source
  • real (non-synthetic, collected by Waymo self-driving cars) · Source
