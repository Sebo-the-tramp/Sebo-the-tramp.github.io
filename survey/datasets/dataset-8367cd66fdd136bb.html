Open dataset ↗

A multi-modal driving dataset delivering quasi-dense 3D ground truth across continuous sequences rich in speed bumps, potholes, irregular surfaces, and off-road segments, spanning ~110 km and 4.7 hours across Germany and Italy. · Source

Depth
quasi-dense aggregated depth (3D ground truth)
Sensors
synchronized global-shutter stereo cameras (2), front and rear LiDARs (2), IMU / LiDAR-inertial odometry

Dimensions

  • 118 sequences · full release · Source
  • ∼350k images · left and right cameras · Source
  • ∼175k stereo pairs · full release · Source
  • ∼110 km / 4.7 hours · full release across Germany and Italy · Source
  • ∼500K valid depth pixels per frame · multi-LiDAR fusion, per frame · Source
  • ∼33k train / ∼11k validation / 16k test stereo pairs · sampled stereo pairs, stratified split · Source

Data types

  • real RGB stereo camera images · Source
  • quasi-dense aggregated depth (3D ground truth) · Source
  • LiDAR point clouds (LAZ) · Source
  • YOLO-format bounding-box labels · Source
  • IMU + GPS + per-wheel motion traces · Source
