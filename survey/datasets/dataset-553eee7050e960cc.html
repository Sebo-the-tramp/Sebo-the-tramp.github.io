Open dataset ↗

A large-scale indoor dataset providing mutually registered 2D, 2.5D and 3D modalities with instance-level semantic and geometric annotations. · Source

Download size
1.09 TB (1085815389545 bytes) · full v1.0 release
Depth
depth and surface normal maps
Sensors
RGB-D sensor (18 HDR RGB + Depth cameras: 6 forward, 6 top, 6 bottom) per scan location

Dimensions

  • 1080 × 1080 px · all RGB/depth/semantic images (full high-definition) · Source
  • 70,496 regular RGB + 1,413 equirectangular RGB (25,434 raw RGBD) · full release · Source
  • 1,413 scan locations · full release · Source
  • 695,878,620 points · colored 3D point cloud (shared with S3DIS) · Source
  • over 6,000 m² · 6 large-scale indoor areas in 3 buildings · Source

Data types

  • RGB images (real, regular + 360° equirectangular) · Source
  • depth and surface normal maps · Source
  • dense per-pixel global XYZ (3D coordinate) images · Source
  • 2D instance-level semantic annotations (per-pixel) · Source
  • 3D meshes (textured and semantic) and colored point cloud · Source
  • raw sensor RGB-D imagery · Source
