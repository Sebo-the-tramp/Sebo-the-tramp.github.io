Open dataset ↗

4D-DRESS is the first real-world 4D dataset of human clothing, capturing 64 outfits across 520 motion sequences and 78k frames with 4D textured scans, vertex-level semantic labels, and fitted SMPL(-X) bodies. · Source

Sensors
high-end multi-view volumetric capture system (real captured imagery)

Dimensions

  • 32 subjects · dataset-wide · Source
  • 64 human outfits (4 dresses, 28 lower, 30 upper, 32 outer garments) · dataset-wide · Source
  • 520 motion sequences · dataset-wide · Source
  • 78k scan frames (150 frames per 5-second sequence at 30 fps) · dataset-wide · Source
  • 1k resolution multi-view images · per frame · Source
  • 80k-face triangle mesh per scan · per frame · Source

Data types

  • real-world 4D textured scans (per-frame triangle mesh + 1k texture map) · Source
  • RGB multi-view captured images and rendered labels · Source
  • vertex-level semantic labels · Source
  • extracted garment meshes and canonical template meshes · Source
  • fitted SMPL(-X) body meshes · Source
