Open dataset ↗

RealX3D is a real-world benchmark dataset for multi-view 3D reconstruction under challenging capture conditions, providing multi-view RGB images, COLMAP sparse reconstructions, and high-precision 3D ground-truth geometry across diverse scenes and degradation types. · Source

Download size
1K<n<10K (number of rows) · Hugging Face dataset card metadata
Depth
point clouds, meshes, and rendered depth maps (3D ground-truth geometry), per-frame metric depth maps rendered from laser-scanned meshes (dense rendered depth)
Sensors
Sony RAW (ARW) camera sensor (real captures, 7 conditions), laser scanning (geometry/depth acquisition pipeline)

Dimensions

  • Full-resolution (~7000×4700) and quarter-resolution (~1800×1200) · JPEG images (data/ and data_4/ directories) · Source
  • 58 distinct scenes · 18 indoor rooms · Source
  • 2491 paired low-quality and reference images (plus same number of RAW captures) · release and assets covered · Source

Data types

  • multi-view RGB images (processed JPEG) · Source
  • Sony RAW (ARW) sensor data with complete EXIF metadata · Source
  • COLMAP sparse reconstructions (camera poses and intrinsics) · Source
  • point clouds, meshes, and rendered depth maps (3D ground-truth geometry) · Source
  • per-frame metric depth maps rendered from laser-scanned meshes (dense rendered depth) · Source
  • real (real-capture, real-world) · Source
