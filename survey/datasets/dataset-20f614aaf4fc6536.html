Open dataset ↗

A large-scale dataset of over 10 million 3D objects aggregated from web sources such as GitHub, Thingiverse, Sketchfab, Polycam, and the Smithsonian. · Source

Download size
10M-100M rows · Hugging Face metadata index (train split, 10,850,997 rows) · over 10 million 3D objects (~10.2M 3D assets) · total objects in the release
Sensors
simulated cameras (Blender rendering), photogrammetry (Polycam mobile app scans)

Dimensions

  • over 10 million 3D objects (10.2M) · total objects in the release · Source
  • 10,850,997 rows · Hugging Face train split metadata · Source
  • over 100 million multi-view rendered images (12 views per object) · renders used to train Zero123-XL · Source
  • ~56% GitHub, ~35% Thingiverse, ~8% Sketchfab, <1% Polycam and Smithsonian · provenance of objects · Source

Data types

  • mixed real and synthetic 3D objects (manually designed, photogrammetry scans, professional artifact scans) · Source
  • 3D model files (obj, glb, gltf, usdz, usd, usda, fbx, stl, dae, ply, abc, blend) · Source
  • rendered RGB images (12 random views per object) · Source
  • textual metadata and CLIP ViT-L/14 image embeddings · Source
  • modalities: Text, 3D · Source
